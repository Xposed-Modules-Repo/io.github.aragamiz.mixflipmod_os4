# MixFlipMod OS4 定制增强版

基于 `MixFlipMod` 面向 **Xiaomi MIX Flip 2 (HyperOS 4)** 定制的增强派生版。

- **源码仓库**：[Aragamiz/mixflipmod-os4](https://github.com/Aragamiz/mixflipmod-os4)
- **安装提示**：使用本派生版前请先卸载原版 `cn.zeldati.mixflipmod`，避免 Hook 冲突；更新后请使用 `--no-incremental` 安装并按需重启。
- **Release Tag 格式**：`9-1.0.12-flip2(re)`（`[versionCode]-[versionName]`）

## 主要增强功能

- 外屏真全屏（隐藏底部 32px 防误触条 & 消除 21px 底栏）与 140px 底部回桌面手势热区
- 外屏状态栏双击锁屏
- 修复 OS4 下失效的外屏通知菜单、控制中心、`3+3` 设备中心与媒体/焦点通知柔光玻璃
- 外屏小部件轻柔光玻璃与 **7 档通透度实时调节**（规避 Vulkan ANR 并支持深底自动反白）
- 微信输入法 4.0.1+ 正置避让 / 倒置全宽适配、外屏拨号盘对齐、计算器与网易云外屏修复
